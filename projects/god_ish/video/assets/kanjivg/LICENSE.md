# KanjiVG stroke data

The `*.svg` files in this folder are from **KanjiVG** by **Ulrich Apel**, unchanged, each with its own licence header.
Each file is named by the 5-digit lowercase hex codepoint of its glyph.

- Source: https://github.com/KanjiVG/kanjivg (files from `https://raw.githubusercontent.com/KanjiVG/kanjivg/master/kanji/<hex>.svg`)
- Website: http://kanjivg.tagaini.net
- Licence: Creative Commons Attribution-Share Alike 3.0 (CC BY-SA 3.0), http://creativecommons.org/licenses/by-sa/3.0/

The new script of god_ish (`video/scenes/new-script.ts`) derives its stroke skeletons from these files at run time.
The derived skeletons and the glyphs drawn from them are distributed under the same licence (CC BY-SA 3.0).
